# 缠论三类买点选股

将结构分析转成有日期、级别、证据和失效条件的研究候选，维护「一买」「二买」「三买」「超跌反弹」四个候选组。默认执行日线辅助筛选，只有用户明确要求严格复核时才切换结构证据门槛。理论依据为用户指定的《教你炒股票》PDF，版本、课号和页码见 [原文索引](references/pdf-source.md)；辅助标签不等于原文严格买点。

## 已确定的默认方式

- 股票池：本次刷新的同花顺「行业龙头」指数 `883917.TI` 成分与沪深主板的交集，排除有明确 ST、退市整理或停牌证据的标的。龙头仅表示来源名单匹配；正式资格字段缺失时，披露资格未完整核验，最低数据门槛见结构规则。用户可明确覆盖范围。
- 周期与门槛：使用最近完整交易日的已发布日线；默认不要求30分钟二次确认。日线连续、末端回落笔已形成、相关买向辅助仍有效等门槛见 [结构复核规则](references/structure-rules.md)。买卖点本身允许仍为 `candidate`，须如实记录原生确认时间；日线输入不证明日线递归级别。
- 类型：原生笔级 `1` 对应一买辅助，`2` 对应二买辅助，`3a/3b` 对应三买辅助；`1p/2s` 不自动并入一买/二买。用户要求严格复核时，独立核对一般一买、常规/小转大/弱二买及三买；第16课方法仅显式指定时启用。
- 超跌反弹：独立候选池，满足日线买向辅助门槛并且近120个交易日内相对各自滚动500日收盘高点曾回撤至少30%，允许当前修复；不要求同时进入前三组，也不把超跌条件叠加为前三组的共同门槛。
- 近期：截至本次完整收盘的最近5个实际交易日，按**每个原生类型首次出现**计时。身份包含股票、周期、结构层、端点、方向和类型；晚满足入组条件、同端点同类型消失后重现均不重置日期。无法核验时间时列待核验，不用端点日或本次扫描日代替。
- 分组：四个候选组只保留近期入选项；历史和待核验在报告单列并移出对应候选组。窗口过期不等于结构失效，同一股票可独立归属多个组，不机械迁移。保留股票本身、其他分组、备注和加入时间；未完成扫描或运行失败不得伪装成有效分类后删除旧成员。
- 龙头标记：确实匹配本次龙头名单的近期候选追加「龙头」标签，已有标签不随近期窗口清除；用户扩展股票池不代表未匹配者也可贴该标签。「持有」「缠论」「中枢震荡」等其他组不在更新范围；中枢震荡仅另列观察，不因此新增分组。
- 执行选股即包含上述分组更新，无需重复询问默认项。用户只要求更新技能、讲解、审查或只读预览时不写分组；本技能不触发下单、通知或定时任务。

## 执行流程

1. **确定本次口径。** 记录北京时间、要求和实际行情截止、辅助或严格模式、股票池与最近5个交易日的具体日期。盘中实时价不代替已完成K线。历史日期研究默认只出报告，不用历史名单覆盖当前组。
2. **检查数据与股票池。** 先读 [项目接口与分组更新](references/project-api.md)，刷新并核对龙头名单完整性，通过项目已有仓库/provider取标准化数据，检查复权、缺口、样本、来源和发布批次。实际截止过期、服务/股票池来源失效或批次混乱时停止相应写入，不把取数失败解释为空候选。
3. **构建候选并追踪时间。** 读 [结构复核规则](references/structure-rules.md)。按类型逐根回放，分别追踪各类型首次出现；同时核对当前日线辅助及独立超跌条件。记录固定输入起点、引擎版本/参数和数据批次；窗口滚动或历史修订不能把旧点刷新为近期。原生点级 `first_seen_at` 不自动等于逐类型首次时间。
4. **按模式核验证据。** 默认核对辅助标签、形成的回落笔、端点及后续有效性，保留严格级别未知项。严格模式按 [原文索引](references/pdf-source.md)核对完整结构及同一收盘截止内的30分钟证据，二买分支独立判断。未完成、缺数据或时间证据不明时列待核验，不用未来K线倒填确认。
5. **分类并生成差集。** 按每种类型分别列近期、历史、待核验、明确失效或范围排除；另列其他辅助及中枢震荡观察。三买的两种原生类型分别计时，任一当前有效类型满足近期及入组条件即可入该组。不默认截取前若干只，不将辅助筛选说成全主板或原文全分支筛选。
6. **更新并回读。** 对四个候选组按参考文档逐项增删，对匹配来源的近期候选追加龙头标记。历史和已完成核验分类的待核验项只留报告，未扫描/运行失败项保留原归属并报告部分完成。只操作授权成员差集，核对股票及其他信息保留。
7. **报告实际结果。** 披露模式、覆盖、近期逐类型名单、历史和待核验独立清单、每组增删与回读状态。区分“新建自选股票”和“已有股票新增标签”；有效近期结果可以为空，不能把研究未完成或严格确认未知说成没有买点。

## 输出要点

先给行情截止、模式、股票池、实际覆盖、近期窗口及整体状态（完整／部分完成／失败）。默认辅助执行完成不代表严格结构研究完成。按目标组分表，至少包含：

| 字段 | 内容 |
| --- | --- |
| 标的与类型 | 代码、名称、目标组、原生类型、龙头来源；严格复核时注明二买分支，多类型分别给依据 |
| 日线证据 | 输入周期与结构级别、结构区间、关键价位、中枢 ZD/ZG、背驰或转折关联证据 |
| 30分钟复核 | 未要求／未复核，或实际覆盖、结构及结果；不得把跳过写为通过 |
| 时间与来源 | 数据截止、价格口径、端点、逐类型首次出现、原生确认时间、回放起点、原文课号/页码、实际引擎版本与参数；实盘首次发现未知时明确写未知 |
| 超跌依据 | 近120日最深回撤、当期500日高点回撤、修复幅度与619日覆盖；只在独立超跌组作为门槛 |
| 状态与失效 | 辅助／结构候选／严格确认，当前有效性、失效条件和证据缺口 |

历史候选和待核验单独列出，待核验区分旧成员、末端待完成及数据缺口，去重统计；仅有其他辅助且已明确未达门槛的观察项不冒充待核验。中枢震荡另列基准中枢、位置、较低级别证据和三卖风险条件，不自动写组。末尾列四个候选组和龙头标记的实际增删、未执行项及回读结果。证据、时间追踪和前后快照写入运行时数据目录的独立研究文件，不直接覆盖自选文件，不提交研究产物到Git。

## 资料与适用边界

- [原文索引](references/pdf-source.md)：用户指定 PDF 的版本、课号、物理页码及解释边界；定义争议回到相关正文核对，不用第三方概括覆盖后续课程的补充。
- [结构复核规则](references/structure-rules.md)：执行判断时读取；定义辅助门槛、独立超跌、逐类型首次出现与分类，并保留严格结构及三买边界规则。
- [项目接口与分组更新](references/project-api.md)：取数或写分组前读取，包含当前已实现能力及会覆盖用户信息的接口。

本技能复用现有项目能力。需要修改、调试或审查应用代码时，先遵循根目录 [CONTRIBUTING.md](../../../CONTRIBUTING.md) 与 [二次开发指南](../../../docs/secondary-development.md)，不要为执行一次研究擅自改动核心服务、策略或数据源配置。
