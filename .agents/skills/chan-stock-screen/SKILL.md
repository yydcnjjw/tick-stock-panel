# 缠论三类买点选股

将结构分析转成有日期、级别、证据和失效条件的研究候选，分别更新「一买」「二买」「三买」自选组。采用流程型分析，由 Agent 复核结构；中枢震荡机会单列观察，不新建分组。理论依据为用户指定的《教你炒股票》PDF，版本、课号和页码见 [原文索引](references/pdf-source.md)。

## 已确定的默认方式

- 股票池：沪深主板，排除 ST、退市整理和停牌标的。每次运行可由用户明确覆盖范围；缺少资格数据的股票进入待核验清单。
- 周期：日线初筛，30分钟复核相关末端结构；分别记录输入周期、实际结构级别及构造依据。日线输入不自动证明日线级别，小级别买点不能替代目标级别买点。
- 类型：一般一买、二买、三买独立复核。第16课方法是用户指定时才启用的一买附加筛选条件，不再作为默认一买定义。
- 二买：覆盖常规型、小转大型、弱二买并分别标注；小转大不强求存在同级别一买，弱二买不因低于前低就自动排除，但都必须复核完整结构及结束证据。
- 中枢震荡：列入独立观察区，记录较低级别的买点与结束证据。触及中枢下沿、单根反弹或盘整背驰标签本身都不足以纳入三类买点组。
- 门槛：日线结构证据及30分钟复核均通过，才新增到对应组。只有辅助信号或证据不足的股票留在报告观察区。
- 分组：名称准确使用「一买」「二买」「三买」。同一股票可归属多个组，各组独立判断；不按“一买→二买→三买”机械迁移。已有「缠论」组不在更新范围。
- 更新：加入新候选，移除有充分证据确认不再符合的旧候选；数据不足的旧成员保留待核验。保留股票本身、其他分组、备注和加入时间。
- 执行选股即包含上述分组更新，无需重复询问已确定的默认项。用户只要求讲解、审查技能或只读预览时不写分组；本技能不触发下单、通知或定时任务。

## 执行流程

1. **确定本次口径。** 记录北京时间、要求的行情截止日、实际数据截止日、股票池与覆盖数量。默认使用最近完整交易日且已发布的日线，并将30分钟复核限制在同一截止日的收盘时间内。盘中实时价仅作补充，不能代替已完成 K 线。历史日期研究默认只出报告，不用历史名单覆盖当前分组。
2. **检查项目数据。** 先读 [项目接口与分组更新](references/project-api.md)。通过项目已有 API、仓库和 provider 获取标准化数据，检查来源、复权口径、交易时段、缺口、样本和数据版本。实际截止落后本次要求时标记过期、待核验，不将旧结论当作当期复核通过。服务不可用或股票池来源失效时停止更新；不把无数据解释为没有候选。
3. **按类型初筛。** 读 [结构复核规则](references/structure-rules.md)，按其课号从 [原文索引](references/pdf-source.md)定位本次所需依据，为三类买点分别构建候选。可用 CZSC 提取笔、中枢和辅助信号；辅助信号用于缩小复核范围，不能作为三类结构的充分条件，也不能作为覆盖原文所有分支的唯一入口。使用批量行情和已有缓存；若只检查了部分股票或算法能覆盖的部分形态，明确报告实际覆盖，不能宣称完成全主板、全类型筛选。
4. **复核日线与30分钟。** 对每个候选给出结构起止、级别依据、关键高低点、中枢边界、背驰或回调证据及当前有效性；二买记录分支，中枢震荡另记小级别证据。记录结构端点时间与首次识别时间；仅凭当前快照无法还原首次识别时间时填未知。样本不足、末端未完成或口径冲突均标为待核验，不能以未来 K 线倒填过去的确认。
5. **生成可核对的清单。** 按「复核通过」「已确认不符合」「待核验」分类，另列辅助信号观察项和中枢震荡观察项。通过项仍称研究候选；只有证据确实达到所声明级别的定义时才使用“严格确认”。不为凑数量放宽规则，不默认截取前若干只，也不把原文中的盈利或安全性论断当作实际收益保证。
6. **更新三个组。** 逐组比较本次结果与现有成员，按参考文档计算新增、移除、保留待核验清单，通过成员接口写入并回读。只有本次实际复核的股票才能得出移除结论；未扫描、被展示数量截断或仅不在用户指定子股票池中，均不能作为删除依据。
7. **报告实际结果。** 列出各类型候选及证据、未知项、每组增删与保留数量、写入和回读状态。一次有效筛选可以没有新增候选；仍要区分“有效空结果”和“研究未完成”。

## 输出要点

先给行情截止、股票池、完成复核数量和整体状态（完整／部分完成／失败）。候选按买点类型分表，至少包含：

| 字段 | 内容 |
| --- | --- |
| 标的与类型 | 代码、名称、目标组、二买分支；多类型分别给出依据 |
| 日线证据 | 输入周期与结构级别、结构区间、关键价位、中枢 ZD/ZG、背驰或转折关联证据 |
| 30分钟复核 | 覆盖时间、相关局部结构、通过或未通过的理由 |
| 时间与来源 | 数据截止、价格口径、结构端点、识别时间、原文课号/页码、CZSC 版本与参数（如使用） |
| 状态与失效 | 辅助／结构候选／严格确认，当前有效性、失效条件和证据缺口 |

中枢震荡观察区列出基准中枢、所处位置、较低级别买点及其完成证据、回到中枢或演化为三卖的观察条件；它不是第四类同级别买点，也不自动写入三个组。报告末尾列三个组的更新明细。待核验旧成员单独展示，避免让组内保留项看起来已通过本轮复核。必要时把证据和更新前后快照写入项目运行时数据目录下的独立研究文件；不要覆盖应用的自选数据文件或把研究产物提交到 Git。

## 资料与适用边界

- [原文索引](references/pdf-source.md)：用户指定 PDF 的版本、课号、物理页码及解释边界；定义争议回到相关正文核对，不用第三方概括覆盖后续课程的补充。
- [结构复核规则](references/structure-rules.md)：执行候选判断时读取，区分原文定义与本技能的研究执行约定，包含三买边界待核验的处理。
- [项目接口与分组更新](references/project-api.md)：取数或写分组前读取，包含当前已实现能力及会覆盖用户信息的接口。

本技能复用现有项目能力。需要修改、调试或审查应用代码时，先遵循根目录 [CONTRIBUTING.md](../../../CONTRIBUTING.md) 与 [二次开发指南](../../../docs/secondary-development.md)，不要为执行一次研究擅自改动核心服务、策略或数据源配置。
