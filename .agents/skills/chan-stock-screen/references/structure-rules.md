# 结构复核规则

## 来源与执行口径

执行口径更新：2026-10-17。依据用户指定《教你炒股票》PDF；下文页码均为从1开始的 PDF 物理页码，原文核对日期、版本和定位见 [原文索引](pdf-source.md)。

原文定义用于严格结构复核；主板龙头股票池、日线辅助、独立超跌、近期窗口及分组处理是用户确认的研究约定，不是原文提供的自动交易系统。默认辅助模式不要求30分钟二次确认。只有用户要求严格复核时，才以以下原文结构与日线/30分钟完整证据作为入选门槛；第16课方法仍仅显式指定时启用。原文后续课程的补充必须一起考虑，尤其是第53、101课对二买的说明。

## 默认日线辅助与独立超跌

默认日线辅助入口检查以下证据，达到入口后再按首次日期区分近期与历史：

1. 属于本次完整龙头名单的沪深主板范围；明确ST、退市整理或停牌者排除。正式状态字段缺失时，最低要求名称已排除ST/退、截止日有成交且样本连续，报告仍须披露资格未完整核验；缺少这些最低证据则待核验。严格模式要求正式资格可验证。
2. 最近完整交易日的已发布日线截至要求日期，样本在所声明输入范围内连续、无重复、OHLC与成交量/额有效。停牌还是供数缺失无法区分时不拼接、不补零，列待核验。
3. 最新笔级买向辅助匹配末端向下笔的同一端点，且该笔已形成。买卖点本身可仍为 `candidate`，不得以笔的 `confirmed=true` 冒充原生买卖点确认。后续同口径低点未跌破端点，且没有更新的卖向辅助替代当前入口。
4. 对目标组至少有一个当前有效的相应原生类型，其逐类型首次出现可核验；落在近期窗口内才入活动组。默认 `1→一买`、`2→二买`、`3a/3b→三买`；`1p`盘整背驰和`2s`类二不并入前两组。递归级别、背驰、中枢确认或三买边界等尚未证明时如实披露，结论仍为辅助候选。

「超跌反弹」独立于前三组：在同样的数据、已形成回落笔及近期买向辅助门槛下，原生 `1/1p/2/2s/3a/3b` 均可作为辅助入口，并另满足：

```text
peak500[t] = max(close[t-499 : t+1])
drawdown[t] = close[t] / peak500[t] - 1
min(drawdown over last 120 trading sessions) <= -0.30
```

使用同一前复权收盘序列，完整计算需619个实际交易日。允许当前已修复，报告近120日最深回撤、当期500日高点回撤及相对120日最低收盘的修复幅度。独立核对数值和阈值附近样本。缺619日只使超跌条件待核验，不自动否定另有证据的一买/二买/三买；仅有 `1p/2s` 且明确未达超跌门槛时是其他辅助观察，不冒充待核验或前三组候选。

## 近期与逐类型首次出现

以下身份用于默认辅助模式。严格复核另记录所声明结构类型的首次可核验证据，不强求必须先有原生标签，也不以原生标签替代原文分支；没有相应首次识别证据仍列待核验。

- **窗口。** 截至要求的完整收盘，取最近5个实际交易日并列出具体日期，首尾均含。用户可覆盖天数；不固定为本次运行的自然日期，也不拿端点日、扫描日或原生确认日代替首次出现日。
- **身份。** 按 `(symbol, asset_type, timeframe, level, endpoint_at, buy/sell, native_type)` 追踪，`3a`与`3b`也各自计时。同一端点多类型分别分类、分别决定组归属；某类型历史不妨碍另一类型近期。
- **证据。** 对同一固定输入起点逐根送入已结束K线，逐前缀观察各类型的当前快照，保存每种身份首次可见的K线日期。记录版本、参数、价格口径、数据generation及回放起点；回放首次可见只在该证据范围内成立，不声称真实实盘首次发现。图表末端快照或确认事件本身不提供充分的首次时间证据。
- **当前引擎限制。** `ChanReplay.point_key` 不含原生类型，其 `first_seen_at` 由同层/端点/方向共享，不能直接复制为每个类型首次日期。研究执行需在逐根回放时另外追踪类型，近期和历史两类都核对；不能只核对近期，再按共享时间把其余全归历史。此追踪可写入独立研究产物，无须为单次筛选改核心引擎或虚构已有API字段。
- **条件晚齐。** 首次出现时笔未形成或超跌条件未满足，后来门槛齐备，仍沿用该类型最早日期。门槛决定当前能否入组，不重置近期计时。
- **消失与重现。** 保存最早日期的记录，不因候选一度消失而清除。相同端点、相同类型重现沿用最早日期；新端点按新身份追踪。截止时已不存在的类型不能仅靠历史记录入组。
- **证据冲突。** 输入窗口滚动、历史复权修订、参数或版本变化不能自动把旧候选刷新为近期；沿用可验证的同身份历史证据，无法比较或日期冲突时列待核验。既有研究只有共享时间、缺少逐类型记录时，也不能猜测其类型首次日期。

例如窗口为10月12日至16日：同一端点二类于9月4日首次出现、三类B于10月15日才出现，则二买属于历史，三买可按10月15日评估近期；10月8日出现的类型即使10月15日回落笔才形成仍属历史；9月出现的同端点同类型在10月15日重现不算新候选。

以下共同证据和三类买卖点定义用于严格复核；不自动成为默认辅助模式的硬门槛。

## 共同证据

- **级别与构造。** 分开声明输入 K 线周期、目标结构级别、次级别及划分依据。中枢须核对连续次级别走势的重叠与完成；日线或30分钟图、三笔重叠、CZSC 笔中枢均不能自动证明递归级别。只验证了笔级结构就称笔级候选；未完成笔、单个分型或辅助信号不能独立确认买点。第17、35、63、64课（pp.42–44、92–94、167–170）。
- **中枢边界。** 固定中枢形成区间及 ZD/ZG，区分重叠区间下沿 ZD 与围绕中枢波动的最低点 DD。趋势中的中枢级别、顺序和不重叠关系均要有证据，还要检查围绕它们的波动是否使结构扩展为更高级别中枢；不能把两个任意紫框当作趋势。边界、比较段不能随结论需要移动。第20课（pp.50–52）。
- **背驰与盘整背驰。** 趋势背驰先有相应级别的趋势，再核对同向比较段、力度和末端结束；盘整背驰是围绕中枢的力度比较，不能直接升级为目标级别一买。以 `a+A+b+B+c` 分析下跌时，检查 A/B 同级别且构成趋势、c 创新低及其内部结构、b/c 的可比性，不能只套字母形状。第24、37、43、53课（pp.59–62、98–99、109–110、133–134）。
- **力度与结束。** 列出实际比较段的时间和价格、力度依据、末端内部结构与结束证据。使用 MACD 时记录参数、比较区间和对应柱面积等实际量；缩柱、金叉或预测剩余柱面积不能替代结构完成。潜在背驰与已确认转折分开，不能预设回到中枢或启动上涨。第24、29、43课（pp.59–62、75–77、109–110）。
- **时间与口径。** 比较价格使用一致且可验证的复权口径。分别记录结构端点、当时首次识别时间和本次数据截止；没有回放或事件记录时，首次识别时间填未知。历史结构事后完整不证明当时可识别；不使用未完成 K 线倒填确认。

## 一买：一般定义

依据第17、24、37、53课（pp.42–44、59–62、98–99、133–134），核对目标级别下跌趋势末端的背驰与结束：

1. 给出趋势起止、至少两个依次向下且按该级别定义不重叠的同级别中枢，以及最终下跌段。单个中枢的震荡、普通下跌或均线走弱不足以证明趋势。
2. 给出可比较下跌段的力度衰减、末端内部结构和向上转折证据；尚在延伸的背驰段只作候选。小级别背驰本身不能冒充目标级别背驰。
3. 日线初筛及30分钟复核覆盖上述相关结构；如还需更低级别定位但无数据，记录证据缺口，不把固定输入周期当作证明。
4. 记录历史一买事件与当前可关注状态。后续扩展、盘整或上涨是不同演化，不因为出现盘整就否定一般一买；若买点依据已被破坏或已成为过去的结构，重新评估当前候选，不永久保留为当前买点。

一般一买不要求额外出现第16课的完整前置组合；只有小转大、没有目标级别背驰时，不补造同级别一买，转到二买相应分支核对。

### 可选：第16课方法

用户指定时才启用（pp.38–41）：在一般一买证据之外，检查同级别的下跌、盘整、再下跌组合及后一跌势的一买，记录每段的起止与级别。该方法面向下跌后转为上涨的情形，转入它要避开的盘整时不再符合该附加筛选。

将“仅不满足第16课条件”与“一般一买结构失效”分开；不把该方法的退出条件套用到一般一买、二买、三买。回到旧中枢的价格区间，也不等于已经形成新的同级别盘整。

## 二买：分支复核

第17课（p.43）给出一买后的首次次级别回调，第53课（pp.133–134）补充小转大情形，第101课（p.253）明确包含低于一买的弱二买。第86课（p.225）的不破一买程序是一种操作办法，不能替代完整定义。

共同记录：起始转折低点及依据、随后次级别向上走势、相关次级别回试、各段起止与完成证据，以及目标级别当前处于转折后发展结构还是持续中枢震荡。不能把任意后续回踩都标成新二买；常规识别以转折后第一次相关回试为基准，更晚的中枢震荡机会按观察区处理（本技能的归类约定）。

| 分支 | 所需结构证据 | 不能据此直接确认 |
| --- | --- | --- |
| 常规型 | 同级别一买关联、随后次级别反弹结束、第一次相关次级别回调完成及其低点关系 | 低点抬高、均线支撑、某个二买辅助信号 |
| 小转大型 | 较小级别转折及其后扩展为目标级别转折的证据，继而完成相关反弹和回试；说明为何没有同级别一买仍可按第53课归类 | 小级别背驰或一次反弹本身；不能把“未查到一买”当作小转大证据 |
| 弱二买 | 一买后相关次级别反弹与回试均完成，回试低于一买，并有回试内部转折、力度及结构结束的证据；第101课指出常见盘整背驰，要报告实际是否成立 | 跌破前低、潜在背驰、下跌仍未结束；不能把任意破位都解释成弱二买 |

以上分支分别复核，证据充分可通过严格模式的二买结构门槛，仍须按本次近期窗口决定是否入组，并标出分支。小转大是转折来源，强弱是回试关系，标签可同时适用，不必强制互斥。二买与三买重合时分别给出两套证据，不因为叫“强二买”就自动加入三买组。

价格高于、等于、低于起始低点都必须报告；等于或低于不再单凭价格判 `fail`，也不单凭原文允许就判 `pass`，仍需完整回试及结束证据。30分钟数据缺少相关起点、反弹或回试时判 `unknown`。所谓“常规”“弱”是结构描述，不是收益评级。

## 三买：离开与第一次回试

依据第20、21、53、58课（pp.50–55、133–134、149）：

1. 固定目标级别最近的基准中枢、形成区间及 ZD/ZG。
2. 复核向上离开的次级别走势及第一次相关次级别回试，两者都要有相应级别与完成证据。不能把一笔、几根上涨 K 线或任意后续回踩直接替代。
3. 比较整段回试最低价与 ZG，不能只看收盘。其最低价严格高于 ZG 且其余证据充分时可通过；明确进入中枢内部则这次回试不符合该中枢三买。
4. **恰好等于 ZG 时列边界待核验。** 第20课 p.51 的文字“不跌破”与同页严格外侧公式、第21课 p.54 的“不触及”有解释差异。本技能不对等号自动判严格通过或结构失败；核对原始精度、复权及原文，仍未消除歧义时记 `unknown`，在严格模式的本轮活动组中隔离，报告单列。不能随意加一个百分比容差来制造突破。

三买不要求此前曾进入一买或二买组。历史成立的三买与当前回试候选分开；后续已确认回入中枢内部时，原三买不再作为当前有效依据，出现新中枢就按新结构重评，不能改动旧边界保留结论。

## 中枢震荡观察区

依据第24、53、86课（pp.60–62、134、224–225），在三类买点清单之外单列，不创建第四个组：

- 固定基准中枢、级别、ZD/ZG 及价格在中枢内、下沿附近或下方的位置；下沿与波动最低点不是同一概念。
- 核对围绕中枢的比较段、盘整背驰或较低级别买点，并记录下行结束及转折证据。只有下沿触及或辅助标签时明确写“位置观察，尚无买点证据”，不能暗示低吸已确认。
- 列出后续分支：重新回到中枢，或向下离开后首次次级别反抽结束仍在下沿外侧而形成三卖风险；回抽未完成时只称风险候选。盘整背驰不保证回到中枢上沿，也不能保证反转。
- 小级别买点保留原级别，不改名为大级别一买/二买。只有另行满足目标级别三类买点证据，才独立评估加入相应组；观察项本身不触发分组写入。

## 卖点与当前有效性

卖点用于风险复核和组员有效性检查，不新增卖点组，也不代表实际卖出指令：

| 类型 | 核对内容 |
| --- | --- |
| 一卖 | 相应级别上涨趋势末端的背驰与结束，按一买方向对称复核 |
| 二卖 | 转折后的相关反弹结束，按二买各分支方向对称复核；不将高点必须低于前高作为所有二卖的定义 |
| 三卖 | 次级别向下离开基准中枢后，首次次级别反抽结束且高点严格低于 ZD；相等沿用三买边界待核验规则 |

风险判断要匹配目标级别与所处阶段。小级别卖点不自动推翻大级别买点；趋势背驰后的第一次反弹可能同时呈现旧中枢三卖形态，也不能据该标签机械否定后续二买（第86课 pp.224–225）。

分开记录历史事件是否成立、当前候选是否仍有效。原一买当前依据被破坏，不自动否定另行成立的弱二买；未出现某个新辅助信号也不自动否定已有结构。不预设结构的固定失效天数或盈利目标；默认最近5日是活动候选的展示窗口，超过窗口可移组，但不能据此宣称结构失效。

## 状态落地

每只股票、每个原生类型先按本次模式记录当前证据是否充分及有效性，再按逐类型时间分类：

| 分类 | 含义 | 活动候选组 |
| --- | --- | --- |
| 近期 | 本次模式的门槛通过，当前有效，逐类型首次出现落在窗口内 | 对应组可入选 |
| 历史 | 本次模式的门槛通过，当前有效，但逐类型首次出现早于窗口 | 只留历史报告，移出对应组 |
| 待核验 | 数据不足、末端未形成、首次日期不明，或本次要求的证据未完成 | 报告单列，移出已完成该分类的旧成员 |
| 明确失效／范围排除 | 仅在有证据时标记，并注明是辅助依据、资格还是严格结构 | 移出对应组，不删除股票 |

默认辅助通过仍可能有严格级别或正式资格未完整核验的共同限制，应单独披露，不能称严格确认。严格模式再对每种结构给出原文判定：

- `pass`：资格已核验，日线初筛与30分钟复核覆盖完整，声明的结构级别和分支证据充分，且当前仍有效；通过结构门槛，近期才入对应组。
- `fail`：有明确的资格排除或相应类型结构不成立／当前已失效的证据；只据此移出对应组。某一分支不成立，不足以否定同类型其他可能分支；仍有未核验分支时报告 `unknown`。
- `unknown`：缺数据、口径冲突、级别未证实、末端未完成、三买等号歧义或初筛未复核；列待核验，不混入严格模式活动组。未扫描或引擎报错、批次冲突等运行失败不算完成分类，不能因此删除旧成员，按接口参考报告部分完成。

同类型的分支合并：资格明确不符时为 `fail`；否则有一个当前有效分支 `pass` 就可通过，无 `pass` 且仍有待核验分支则为 `unknown`，只有充分复核后均不符合才为 `fail`。不同买点类型继续独立判断。

这些是研究状态，不是新增API字段。原文允许某类结构不证明当前股票满足它；辅助信号为假、首次可计算只建立基线、结果为空、仅有笔级证据均不能单独产生全类型 `fail`。历史和待核验移组是用户确认的展示规则，不冒充结构失败。中枢震荡观察本身不参加四个候选组的增删差集。
