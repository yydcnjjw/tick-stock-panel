## 筛选口径

对每个交易日定义：实体 `B = |C - O|`，振幅 `R = H - L`，下影 `LS = min(O, C) - L`，上影 `US = H - max(O, C)`。一个事件必须同时满足：

1. `R > 0` 且 `B > 0`，排除一字线和十字星；
2. `LS >= 2 × B`；
3. `US <= 0.25 × B`；
4. 收盘位置 `(C - L) / R >= 65%`；
5. 信号日前 5 个交易日累计跌幅 `C[t-1] / C[t-6] - 1 <= -3%`；
6. 上述 5 个收盘变化中至少 4 个为负；
7. 信号日最低价不高于此前 5 个交易日的最低价，即形成近 6 日新低。

第 5—7 条是本文对“锤子必须出现在下跌之后”的可复现定义。这是本报告的**最终收紧口径**：它比只看单根 K 线严格，会漏掉缓慢下跌、V 型急跌后已先反弹、横盘震荡中的视觉锤子；这是为了降噪所作的有意取舍。筛选不使用成交量，因此表中的量比只作事后信号质量描述。

确认状态也预先固定：

- **收盘确认**：下一有行情交易日的收盘价严格高于信号日最高价；
- **盘中突破**：下一有行情交易日最高价高于信号日最高价，但收盘未站上；
- **未突破**：下一有行情交易日最高价未高于信号日最高价；
- **失效**：信号后的任一有行情交易日，最低价严格低于信号日最低价；本报告持续追踪到 2026-08-28。确认与失效可以在同一天同时发生，例如先下破再收回。
- **截至周五强势有效**：次日收盘确认、截至 8 月 28 日从未失效，且 8 月 28 日收盘仍严格高于信号日最高价。

## 已证实事实、合理推断与无法证实说法

### 已证实事实

- 按本文预先列明的七项条件，8 月 24—28 日共有 21 个严格候选；8 月 28 日仅晨丰科技和润本股份两只。
- 两只最新候选都有零上影、至少两倍下影和近 6 日新低，但都是收盘低于开盘的阴线锤子。
- 晨丰科技 8 月 28 日成交量高于前 5 日均量，润本股份明显低于前 5 日均量。
- 较早的 19 个事件中，次日确认和截至 8 月 28 日的持续失效状态如表所列；这些是事后行情事实，不是可成交回测。

### 合理推断

- 晨丰科技得到的量能佐证强于润本股份，因此在本文定义下是两只待确认候选中相对更强的一只；仍需下一有行情交易日收盘突破 24.23 才构成价格确认。
- 润本股份缩量形成长下影，可能只是抛压暂时减弱而非主动需求增强；若没有后续放量站上 20.65，单根形态的解释力较弱。
- 次日只盘中越过高点但收盘回落的 4 个事件，应视为“尝试确认失败或未完成”，不与收盘确认混为一类。

### 无法证实或应拒绝的说法

- “出现锤子线就会反转”或“历史上 10/19 已确认，所以胜率是 52.6%”。本样本只有一周，且确认不是盈利、成交和退出结果。
- “长下影证明主力吸筹、洗盘或护盘”。公开日 K 无法识别账户、主动买卖方向和交易动机。
- “失效位一定可以止损成交”。A 股 T+1、跳空、跌停、停牌、流动性和交易成本都可能使实际成交偏离该价。

## 复现方法

以下命令只使用 Python 标准库和正在运行的本地 API。它固定检查 `as_of=2026-08-28`，并用十进制定点数避免 `0.25 × 实体` 边界上的浮点误差：

```bash
python3 - <<'PY'
import json
import urllib.request
from decimal import Decimal as D

base = "http://127.0.0.1:3018"
snap = json.load(urllib.request.urlopen(base + "/api/screener/market-snapshot"))
assert snap["as_of"] == "2026-08-28", snap["as_of"]
names = {row["symbol"]: row["name"] for row in snap["rows"]}
request = urllib.request.Request(
    base + "/api/kline/daily-batch",
    data=json.dumps({"symbols": list(names), "days": 20}).encode(),
    headers={"Content-Type": "application/json"},
)
daily = json.load(urllib.request.urlopen(request, timeout=120))["data"]
window = {f"2026-08-{day:02}" for day in range(24, 29)}

hits = []
for symbol, rows in daily.items():
    rows = sorted(rows, key=lambda row: row["date"])
    for i, row in enumerate(rows):
        if row["date"] not in window or i < 6:
            continue
        o, h, l, c = (D(str(row[key])) for key in ("open", "high", "low", "close"))
        price_range, body = h - l, abs(c - o)
        if price_range <= 0 or body <= 0:
            continue
        lower = min(o, c) - l
        upper = h - max(o, c)
        close_position = (c - l) / price_range
        pre_return = D(str(rows[i - 1]["close"])) / D(str(rows[i - 6]["close"])) - 1
        down_days = sum(
            D(str(rows[j]["close"])) < D(str(rows[j - 1]["close"]))
            for j in range(i - 5, i)
        )
        new_low = l <= min(D(str(x["low"])) for x in rows[i - 5:i])
        if (
            lower >= 2 * body
            and upper <= D("0.25") * body
            and close_position >= D("0.65")
            and pre_return <= D("-0.03")
            and down_days >= 4
            and new_low
        ):
            later = rows[i + 1:]
            next_day = later[0] if later else None
            confirmed = bool(next_day and D(str(next_day["close"])) > h)
            invalidated = any(D(str(x["low"])) < l for x in later)
            friday = next((x for x in rows if x["date"] == "2026-08-28"), None)
            strong_effective = bool(
                confirmed
                and not invalidated
                and friday
                and D(str(friday["close"])) > h
            )
            hits.append(
                (row["date"], symbol, names[symbol], row,
                 next_day, invalidated, strong_effective)
            )

for hit in sorted(hits, reverse=True):
    print(hit)
print("events:", len(hits), "symbols:", len({hit[1] for hit in hits}))
PY
```

## 局限

- 全市场集合来自 2026-08-28 最新快照和 2026-08-29 当前证券维表，不是每个历史交易日冻结的点时股票池；退市、长期停牌或后来才补入维表的证券可能造成轻微存续偏差。
- 本文只检查日线价格形态，没有过滤财报、公告、行业、流动性、上市天数、停牌和涨跌停状态；`ST星农` 因此保留在机械全表中，但已排除在优先观察名单之外，且不能和普通 10%/20% 涨跌幅股票直接类比。
- 第一方交易所行情只抽查 5 只，没有逐只复刻整个全市场数据集；北京证券交易所候选仅由本地标准化行情支撑，未在本次抽查中再取北交所原始接口。
- 次日确认只观察 OHLC，不知道盘中突破持续时间，也不模拟集合竞价、T+1、滑点、费用和不可成交；失效位不是订单建议。
- 阈值是研究者定义，不是交易所或项目内置的官方“锤子线”标准。改动前置跌幅、影线比例或确认方式都会改变候选数，不能在看过结果后挑选最有利参数。
