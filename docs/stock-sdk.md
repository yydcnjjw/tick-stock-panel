# stock-sdk 本地数据源插件

本地分支保留 `backend/app/plugins/stocksdk/`，通过现有 `plugin.yaml`
发现与 provider 注册机制加载。上游 v0.3.12 不包含该插件，本地恢复不改变
其他插件、能力路由或用户数据。

插件声明 `daily`、`adj_factor`、`minute`、`realtime` 四个数据集；
1 分钟历史深度声明为最近 5 个交易日。分钟时间转换为北京时间墙钟，
实时涨跌幅由百分数转小数，实时成交额由万元转元。

分钟批次请求失败会向同步服务抛出错误，不报告为空数据成功。
历史分钟开盘价被识别为全天常量时保留缺失值，不用前收盘价伪造。
数据覆盖和质量仍取决于来源，恢复插件不保证每个标的都有完整分钟历史。

Docker 继续默认 `INCLUDE_STOCKSDK=0`。本地 Compose 已配置为 `1`，
会安装 Node.js 并从独立构建阶段复制 stock-sdk 依赖。开发环境可在插件目录
执行 `npm ci`。缺少 Node.js 或依赖时，插件显示不可用且不影响其他数据源启动。

本次恢复沿用 rebase 前的插件源码和分钟失败处理，不自动修改数据源偏好，
不迁移或覆盖历史行情。回归覆盖插件发现、依赖缺失隔离、分钟时区、
缺失开盘价、实时单位以及 Node 桥接的空结果和请求失败。
