# 中枢震荡回测策略

策略 ID: `chan_center_range`。基于上游 `77e90350dc8eb4d2ed5cf66b6cd4c88ff8c88b3f` 开发。
这是日线 chan.py 笔级辅助结构实验，不声称严格递归级别的缠论买卖点。

## 原版规则

缺少 `params.rule_set` 的历史请求继续使用原版。页面新建请求默认选择「完整新版」，并明确携带规则方案。

1. 目标股票池是历史每一天当时有资格的沪深主板，排除当时的 ST、退市股票；不使用今天的观察分组回测过去。
2. 对前复权已收盘日线按时间顺序回放。只取当时最新中枢，不回退选择更早的宽中枢。宽度 `(ZG-ZD)/ZD >= 0.10`，末端在最近 20 个市场交易日内，初始至少 3 笔已完成；中枢整体可继续演化。
3. 底分型低点在 `[ZD, ZD+0.2*(ZG-ZD)]` 且确认日收盘仍在中枢内，产生区间买入信号。顶分型高点在 `[ZG-0.2*(ZG-ZD), ZG]`，产生区间退出信号。20%/80% 本身不触发交易。
4. 分型沿用固定版本 chan.py 的包含处理；中间合并 K 线的极值日期为端点，右侧合并 K 线首次出现且该输入日线收盘时才可观察。相同分型不重复发布。不得使用最终图形回填端点日信号。
5. 只有实际买入成交才锁定该信号对应的中枢上下沿。不加仓。收盘低于固定下沿，优先在下一交易日开盘请求退出；没有最长持仓天数。
6. 中枢起点改变或上下沿改变转入 123 阶段；单纯末端延长不切换。只接收结构端点严格晚于切换日、随后首次确认的笔级 `1/2/3a/3b` 事件，不包含 `1p/2s`。时间过滤不证明事件属于同一个中枢。
7. 123 阶段允许中枢上方入场，但信号收盘不得低于参考下沿；入场时最新参考中枢仍须符合宽度、近期及初始 3 笔条件。再次成交使用新参考边界。持仓等待卖点或固定下沿止损；空仓等待买点。
8. 清仓后重新筛选。重复区间入场必须出现端点晚于上次实际退出日的新底分型，不能复用旧分型。不在同一天清仓再建仓。同一收盘同时满足买卖条件时卖出优先。
9. 买单仅下一个市场交易日开盘有效，缺行情、停牌、涨停、资金或仓位不足则作废，等待新信号。卖出受阻则保留退出请求。成交使用实际开盘价、现有成本、100 股整手、仓位及可交易约束。
10. 仅支持仓位模式、双侧次交易日开盘；不支持叠加策略、分钟成交和额外止盈止损。区间结束时对未平仓头寸继续估值并报告 `open_positions`，不制造一个策略卖点。

## 数据边界与本版交付

目前仓库使用当前 instruments 维表，尚未接入完整的逐日上市、退市与 ST 资格历史。
默认在策略详情及回测页面显示阻断原因；未显式启用探索性口径时，回测及优化入口在读行情前拒绝运行。
要报告完整历史股票池的收益，必须接入并验证完整历史资格、市场交易日覆盖及行情质量，不能将当天名称视为历史资格。

用户可显式勾选「启用探索性回测（历史资格未核验）」或传入 `params.exploratory=true`。
该口径使用载入历史行情中的沪深主板股票逐日筛选，不使用今天的观察分组，不默认按当前名称排除历史 ST。
收益只描述现有行情样本及成交假设；历史股票池完整性、ST、退市资格与涨跌停估计仍有限制。
探索性选项不解除其他策略的阻断，不开放本策略的参数优化、普通选股或监控。
结果的 `stats.research_scope` 保存口径说明、载入日期、有效股票数、缺失或非法行情单元数和中枢资格覆盖，页面及 CSV 导出保留说明。
`missing_or_invalid_symbol_days` 包含上市前、退市后、停牌和数据缺口，不能把这个总数全部解释为漏数。

正确性测试使用明确标注的合成数据。代码前缀只确定沪深主板范围，不宣称已完成历史 ST/退市筛选。
缺失或非法行情会中断结构回放；不跨缺失右侧 K 线确认分型。固定下沿风控仍可使用有效收盘价。

预热请求为 1000 根；从实际载入起点连续回放。它不是图表的每日滚动 1000 根重算，比较结果必须固定输入起点、截止日与 chan.py profile。
最近 20 日及买单有效期使用输入市场日轴；正式运行前必须证明这个日轴覆盖完整交易日历，不能以个股下一条记录代替下一市场交易日。

## 实现与兼容

- `ChanReplay.fractal_events` 发布本次更新首次可见的分型；原 BSP 返回值和确认规则保持兼容。
- `CenterFeatures` 是只读、按信号日对齐的结构观察矩阵，随信号过滤和切片传递；日期使用绝对日序避免切片改变端点时间。
- `CenterBook` 由组合撮合器逐日推进，通过实际成交/退出回调管理固定边界和阶段。未成交的候选不产生虚构持仓。
- `SignalMatrix` / `MarketMatrix` 新增可空字段，仅含中枢观察的矩阵启用新规则；旧策略仍按原有下一条有效行情延迟处理。
- 成交审计增加可空 `center_reference`，包含固定上下沿及入场阶段。
- API 增加可选 `backtest_only` / `backtest_block_reason`，前端据此展示明确的数据阻断状态。普通选股批量任务跳过此策略，监控拒绝使用。
- 不改 Parquet、行情 generation、用户分组或已有策略配置；被阻断的策略不扩大公共预热缓存。升级时重点复核矩阵切片/合并与组合撮合成交回调。

## 已确认的第二版与对照方案

`params.rule_set` 可选「原版」「仅成交门槛」「仅扩大退出」「仅风险定仓」「完整新版」。前三个单项改动分别与原版比较，完整新版同时启用三个改动；不自动搜索参数。所有方案使用同一原生结构、宽度降序与持仓阶段切换规则。

- **成交门槛**：区间底分型买单的次市场交易日开盘价 `P` 必须高于信号参考下沿 `ZD`，且 `(P-ZD)/(ZG-ZD) <= 0.40`、`(P-ZD)/P <= 0.05`。不满足即作废，不重试，不锁定中枢，也不占用持仓槽位。阈值包含边界，仅容忍 float32 的舍入误差。123 买点不套区间位置与 5% 门槛，但启用成交门槛或风险定仓时两阶段均要求 `P > ZD`。
- **扩大退出**：区间阶段顶分型高点 `>= ZG-0.2*(ZG-ZD)` 即可触发，取消不得高于 `ZG` 的限制。仍需等待分型首次可观察日收盘，次市场日开盘退出；123 阶段保留原卖点。收盘低于冻结 `ZD` 仍优先止损。
- **风险定仓**：每笔新仓的含双边成本计划损失最多为当时权益的 1%，每只建仓成本最多为权益的 50%，继续受最大持仓数、总敞口、现金与100股整手约束。不加仓、不将剩余风险额度分摊给其他股票。

权益基数 `E` 在当日卖出处理后、买入前冻结：现金加未卖持仓最近有效收盘价估值。当天所有新仓使用同一基数，不使用当日收盘未来数据，也不让第一笔新仓的旧收盘估值改变第二笔额度。

每股计划风险为 `P*(1+c_buy)-ZD*(1-c_sell)`；股数取风险预算、50%资金上限、原组合目标仓位、现金与剩余总敞口所允许的最小值，再向下取100股整手。滑点已在 `c_buy/c_sell` 中计入，不重复加在 `P` 上。

这里的1%只是假定在ZD成交的计划风险。实际仍是收盘破位、次日开盘退出，破位穿透、隔夜变化和不可成交可能令实际损失超出预算。

新增门槛与风险检查在实际占槽之前执行，按原宽度排序继续检查后续候选；不足一手不会阻止后面的合格候选。基准原版保留原撮合路径，以复现之前的实验。

结果保存生效后的完整方案参数和 `stats.center_rules`，风险定仓的 `center_reference` 增加可选的入场权益、风险预算和计划风险金额；期末未平仓头寸通过 `stats.open_position_details` 保留审计，不制造平仓成交。旧记录缺少新增字段时继续可读。

## 缠论结构发散实验（2026-09-28）

本轮按用户追加的“基于缠论、兼顾收益与最大回撤”目标扩展研究。阅读原文第20、24、37、53课后，将区间分型、确认笔级1/2/3事件、确认买点后的回踩分型、中枢位置关系和退出方式拆开比较。原文来源及物理页码见技能 `chan-stock-screen/references/pdf-source.md`。中枢下沿ZD与波动最低点DD不同；本轮保留ZD收盘风控作为实验执行规则，不把触及ZD视为原文定义的卖点。

先运行34个方案（含3个旧版对照），再在开发窗口运行10个粗粒度组合；全部失败方案、零交易方案和原先48个均线/量价/风控对照均保留。2025-04至09月、2026-04至09月参与选择；锁定候选后才读取2024-04至09月、2025-10至2026-03月结果。后两段只称未参与本轮选择的历史对照，不能称严格前向验证。

### 页面新增的两个实验方案

`中枢结构实验版` 和 `中枢结构实验保守版` 保持为手动可选，默认仍是完整新版，旧请求仍回退原版。**两个新方案均未通过跨区间收益与回撤检验，不建议替换默认。** 详情参数的 `option_details` 提供逐方案说明和风险比例，页面及结果导出显示实际比例。

共同规则如下：

- 最新软件中枢的ZD、ZG均不低于上一个不同起点的已观察软件中枢。相同起点的边界修订只更新当前中枢；缺失或未知结构清空位置记忆，未观察到前中枢则拒绝入场。记忆从回测正式窗口起逐日建立。此条件不验证前中枢的严格递归级别，也未比较GG/DD，不能称严格上涨趋势。
- 始终采用最新合格宽中枢下部20%的底分型入场，不因中枢改边切换为123入场。信号收盘必须在中枢内部，实际开盘必须高于ZD，不使用第二版40%位置/5%距离门槛。
- 候选按信号日收盘 `C` 的 `(ZG-C)/max(C-ZD, 0.01*C)` 降序。同分保留已有股票轴顺序。1%分母底线只用于排序，不改变止损或定仓距离。这是区间潜在空间排序，不是已知的真实盈亏比。
- 成交后冻结ZD/ZG。收盘跌破ZD优先；否则上部20%及上方顶分型或当日新确认的笔级卖点均可退出。保留T+1、次市场日开盘、卖出受阻延期、整手、现金和最多持仓数约束。
- 标准实验版每笔含成本计划风险1%，保守版0.5%；两者单股资金上限50%。它们使用相同信号规则，但整手、风险额度及可用仓位可能使实际成交数量和后续机会不同。

仅在内部研究配置中增加结构事件选择、确认后回踩、中枢位置、收盘目标/持仓期限/移动退出、历史量价过滤和定仓风险底线等控制。所有新增控制默认关闭，不开放原先阻断的公共自动参数优化入口。非缠论量价实验保留为对照，不加入页面策略预设。

历史上下文由连续有效的已收盘行情计算，缺口窗口未知；ATR采用14根真实波幅简单均值。风险底线只改变定仓，不移动冻结ZD。上下文与观察矩阵一起只读、切片并计入内存统计，不引入持久结构缓存或行情schema修改。

### 验证结果与结论

同为10万元、最多2只、双边佣金0.02%和双边5bps滑点，下表为区间收益 / 最大回撤，均非年化：

| 窗口 | 完整新版 | 结构实验版 | 结构实验保守版 |
| --- | --- | --- | --- |
| 2025-04-01—09-30（开发） | +0.63% / 8.17% | +5.87% / 4.32% | +3.70% / 2.16% |
| 2026-04-01—09-28（开发） | −14.49% / 19.17% | +2.04% / 8.15% | +0.18% / 4.82% |
| 2024-04-01—09-30（保留） | +3.91% / 12.32% | −13.12% / 20.40% | −7.60% / 11.42% |
| 2025-10-01—2026-03-31（保留） | +20.21% / 11.99% | −0.31% / 7.31% | −0.52% / 4.25% |

开发窗口的改善未延续到保留窗口；降低预算能降低回撤，但不证明信号有效。提高成本后结论不变。原版在两个保留窗口分别盈利19.20%、22.67%，也说明不能仅按2026开发期挑选赢家。本轮未找到跨窗口稳定同时改善收益和回撤的方案，未据保留结果继续调参。

受影响后端回归442项通过、6项既有用例跳过；最后名称和元数据调整后的29项定向测试通过。新增结构测试覆盖事件首次确认而非端点成交、中心改边与新中心区别、前中枢未知、缺口、回踩窗口、同日卖点优先。前端生产构建通过；隔离预览验证七方案、0.5%风险显示、旧策略、探索性门控、桌面/窄屏、明暗主题和实际模拟结果的CSV导出。结果展示使用本轮真实模拟数据装配的UI夹具，不冒充另一次API收益运行。

新增Python文件和本次改动无新增Ruff问题；既有撮合器60项历史Ruff告警保持不变。旧五方案开发窗口成交与权益精确复现。数据generation及无关工作区改动未修改。未部署或替换正在运行的服务。

## 第24课止损实验版（2026-09-29）

页面「中枢震荡: 分型 + 123买卖点」的规则方案新增「第24课止损实验版」。旧方案及默认选择保持原状；新方案显式传入 `params.rule_set`，继续受探索性数据门控约束。以下是软件实验约定，不是严格递归级别的背驰或三卖证明，尚未完成收益对照。

依据为[第24课《MACD对背弛的辅助判断》，PDF物理59—62页](https://resources.chzhshch.blog/docs/marketstudent/%E7%BC%A0%E4%B8%AD%E8%AF%B4%E7%A6%85%E6%96%87%E9%9B%86--%E6%95%99%E4%BD%A0%E7%82%92%E8%82%A1%E7%A5%A8%E7%B3%BB%E5%88%97.pdf#page=59)。本版区分下沿价格风控、力度辅助证据和首次反弹结果；不将MACD减弱直接当作中枢回归保证。

### 证据与入场

- 复用固定 chan.py profile。A为某软件中枢的进入笔，C为其紧邻离开笔；均为下降笔，A、C及中枢内部至少三笔须为当时的原生 `is_sure` 状态。C低点严格低于A低点和ZD。
- 面积是各笔起止原始K线之间**全部负MACD柱绝对值之和**，包括端点；要求 `0 < C面积 < A面积`。不比较单根柱、峰值或截断的半波面积，不改共享BSP profile中的 `macd_algo=peak`。
- 原生完成笔仍可修订。本版记录首次可观察日及撤销事件，不称不可撤销的确认；不用未来完成面积回填。单根笔没有完整次级别走势类型和B内部零轴回拉的严格级别证明，因此统一标记 `daily_pen_auxiliary`。
- 仅在证据首次可观察日、匹配当时最新合格宽中枢、首次反弹尚未完成、收盘位于 `(ZD,ZG]` 时下单。再次入场的C端点必须晚于上次实际退出日。实际次市场交易日开盘也必须位于 `(ZD,ZG]`；缺失、涨停或跳空出界作废，不顺延买单。
- 本版不沿用“下部20%底分型即可买入”，也不叠加40%/5%成交门槛或前中枢不下移过滤；排序沿用宽度。这样记录的是一个独立的证据入场和止损实验。

### 风控、首次反弹与退出

- 实际成交时冻结ZD/ZG和该C低点L。每股计划风险为 `P*(1+c_buy)-L*(1-c_sell)`，每笔计划预算为建仓前权益1%，单股最多50%，按100股整手向下取整。可沿用10万元、最多2只；该额度不是跳空或跌停情况下的损失上限。
- 最高优先级：有效收盘价 `<=L`，请求次市场交易日开盘退出。L在整笔持仓中不下移。
- 对仍有效的C证据，收盘跌破ZD而未触及L时，允许等待从该C端点开始的第一根完成上升笔。其高点严格低于冻结ZD时触发「首次反弹未回中枢」退出；高点等于ZD按未知处理，大于ZD视为已回区间。这两种情形均结束本次例外，后续收盘再破ZD恢复原下沿止损。
- 同一冻结中枢后来出现新的有效C证据，可重新观察其首次反弹，但C端点必须更新且C低点不得低于L。不同中枢、旧端点或更低的C低点均不能刷新例外。
- 原生证据撤销、行情缺口会立即取消例外。没有有效例外时，收盘低于冻结ZD照常退出；无有效收盘时不能假定可以成交。上部及上方顶分型、新确认的原有卖点仍可退出，不因等待反弹屏蔽它们。
- 保留T+1、收盘信号与次日开盘分离、卖出受阻保留原请求、现金/敞口约束、期末不强制卖出。后来的背驰证据不能取消已排队的卖单。
