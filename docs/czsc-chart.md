# CZSC 多周期结构图

状态：已实现。支持 A 股股票 1 分钟、5 分钟、30 分钟、日线、周线结构图及各周期六类辅助信号，通过个股详情底部「查看 CZSC 多周期结构图」进入，也可直接打开 `/czsc?symbol=600415.SH&timeframe=30m`。不带周期时仍为日线。后端需启用 `czsc` 可选依赖，安装方式见 [辅助信号文档](./czsc-signals.md)。

## 多周期扩展（2026-09-18 已确认并实现）

- 保留股票日线，新增 `1m`、`5m`、`30m`、`1w`，同一页面单图切换，默认日线；URL 保存 `timeframe`，切股保持周期。
- 每周期独立展示分型、笔、笔中枢、未完成结构、六类辅助信号、量能与 MACD。首次成立标记使用该周期完整时间，不将日线信号投影到分钟图。
- 仅用已结束 K 线。分钟标签为北京时间结束时点，09:31–11:30 与 13:01–15:00 分段聚合；可选 09:30 竞价行并入首桶、量额相加，不抵充正常分钟。拒绝其他标签口径，避免静默错位。
- 分钟合法 OHLC 为正、量额允许零；缺价格、缺分钟或非法数值的桶作为结构断点，不补价格、不画伪 K。缺失整日与节假日/停牌无法仅靠本地数据区分，覆盖说明不承诺完整市场日历。
- 周线从已发布日线按自然周聚合，标在该周最后实际日线日期。当前没有完整交易日历，保守在北京时间周五 15:00 后认定该周结束（节前短周也遵循此边界），不把星期三缺少后续日线当作已结束周。
- 目标读取最近 1000 根目标周期 K，默认展示 250 根。分析窗口含用于中断计算的缺口位置，页面另列实际有效 K 线数。周线最多读取 5005 根日线，分钟最多读取目标分钟数加边界余量；不足时明确显示实际覆盖和信号不可计算性，提供数据管理入口。
- 图表 GET 只读本地已发布日线/已落盘分钟，不自动发起远程拉取，不推断供应商复权状态。分钟缓存以仓库分区指纹和闭合截止为边界，读前后版本变化则失败，失败不伪装为空数据。
- 分钟图提供「同步分钟数据」按钮，显式调用既有单股同步 POST 补取近期历史，完成后失效该股三个分钟周期及分时缓存；切股后的迟到同步结果不覆盖当前股票。自定义源请求失败会直接显示在图表页，源正常返回但无可写入记录也不再显示同步成功。「刷新」只重新读取本地数据。
- 可在设置中选择独立插件「交易所分钟行情」：沪深股票/ETF 的 1 分钟原始价，成交量由股转为手，分钟时间为北京墙钟；不覆盖北交所或指数。`stock-sdk` 仅声明近 5 个交易日的 1 分钟历史，且部分历史开盘价可能缺失。任一来源的实际历史覆盖均须以页面有效 K 线数量为准。

## 功能范围

- 集成到 TickFlow 应用，独立 CZSC 页面并提供个股详情入口。
- 首版支持 A 股股票日线，展示结构图和现有六个 CZSC 日线辅助信号。
- 沿用 [领域词汇表](../CONTEXT.md) 中结构图、辅助信号标记与首次成立触发的区别。

## 图表操作

- 使用静态扩展路由 `/czsc`，以 `symbol` 查询参数携带股票；从个股详情底部进入时带入当前股票。页面复用既有股票搜索，可切换标的，支持地址直接访问和刷新。
- 显示日 K、顶底分型、已完成笔、CZSC 笔中枢、未完成结构、成交量和 MACD。分型、笔、中枢、未完成结构和辅助信号可分别开关。
- 已完成笔用实线；末端未完成结构用虚线，并在图例中明确其可能变化。笔中枢画出时间范围及价格上下沿，只展示至少三笔且通过原生有效性检查的结果，不称为严格递归或线段中枢。
- 六类辅助信号按既有首次成立触发日标记，鼠标或触控查看日期、名称和价格。它们与分型、笔端点及成交标记使用不同样式。
- 首版展示截至实际最新已收盘日线的结构快照。缩放和拖动只改变可见范围，不按可见窗口重新识别结构；暂不加入历史截止日重算、逐根回放和分钟周期。
- 默认展示最近约 250 根日 K，可缩放浏览已加载数据。固定读取目标为最近 1000 根实际交易日 K；不足时使用已有数据并说明覆盖情况。读取根数与屏幕显示根数分开，不能将 API 的自然日参数当成交易日根数。
- 首次进入和切换股票时加载，提供手动刷新；显示实际行情截止日、读取范围、结构覆盖范围及刷新时间。后台刷新保留同一股票的上一份结果，切股不显示上一只股票数据；刷新失败保留旧结果并标明状态。

## 数据与算法边界

- 使用现有仓库中的股票 enriched 日线及其价格口径，不调用带远程兜底和实时日 K 拼接的 HTTP 日线接口，也不新增供应商取数通道。保留来源与价格口径的证据边界，不把缺少复权证据的序列宣称为已验证前复权。
- 按北京时间收盘时点筛选日线，当日 15:00 前排除当日，未来日期排除。显示本地实际截止日，不追加实时内存快照。发布 generation 只证明批次一致，本地数据没有逐根定版标识，尾日可能待盘后同步校正，不能宣称已经独立核验最终收盘值。
- 固定使用当前可选依赖 CZSC 1.0.1、`min_bi_len=6`、`max_bi_num=50` 和现有六类辅助算法参数。成交量沿用手，并只在 RawBar 边界乘 100 转股；金额为元。结构对象只保留有限笔，页面明确结构覆盖起点，不承诺全部已加载 K 线都有结构覆盖。
- 输入按交易日期升序，重复日期拒绝，非法 OHLC/量额沿用既有中断及重新建立基线语义。图层不得跨无效数据连接为完整结构；缺失数据不能填零造 K。
- 图表结构是当前截止时点的结构快照；结构端点所属日期不代表该结构当时已经被识别。历史辅助事件仍逐根回放记录，禁止从最终结构反推并回填买卖信号。
- 共用既有逐根计算过程，保持 `czsc_signals.compute()` 的输出、首次基线、不可计算原因和默认按需加载行为。仅图表请求收集额外结构，普通策略和回测不承担结构序列化成本。
- 相同输入前缀、版本及参数下，辅助信号必须与既有计算一致。不同历史起点、缺口或复权修订可能改变结果；1000 根读取目标不保证所有信号就绪，也不保证与采用其他预热区间的回测逐项相同。
- 未安装依赖、版本不符、非股票资产、空数据、样本不足和加载失败都有明确状态；不可计算与未触发分开。

## 接入方式

整体属于 L3 局部源码扩展，前端入口使用已有 L2 注册能力。原因是后端扩展仓库协议目前只公开股票名称查询，现有共享图表也没有斜向笔和价格区间中枢契约。

1. 在 `frontend/src/custom/czsc/extension.tsx` 注册独立页面与 `stock-preview.footer` 入口，复用股票搜索，不修改详情标签页契约。
2. 给 `EChartsCandlestick` 增加默认无图层的可选线段、价格矩形和结构点参数，复用已有 K 线、量能、MACD、缩放和主题支持；不复制整套图表组件。
3. 在既有 K 线 router 增加薄端点 `GET /api/kline/czsc-daily?symbol=...`，具体读取、按需回放和结果映射放入独立 service；复用真实仓库，不扩建二开通用协议。现有日线仓库会以盘中内存覆盖尾日，因此新增窄读取方法 `get_daily_published()`，让图表只读已发布 enriched 快照；即使已过 15:00，也不把尚未发布的内存尾行当作定版历史。
4. 将既有 CZSC 逐根回放提取成共享的内部过程，保持原 `compute()` 调用方契约不变，为图表增加只在需要时使用的结构输出。
5. 前端请求和类型仍集中于 `api.ts`，查询键仍集中于 `queryKeys.ts`；股票、周期、算法契约与读取窗口进入键，图层开关不触发重新取数。

响应一次提供一致快照的日 K、结构、辅助信号事件及覆盖元数据，避免前端将不同批次的行情与结构拼在一起。`status` 区分 `ready`、`empty`、`unavailable`；非法或非股票标的被拒绝，发布中及读取失败返回明确错误。

## 缓存与兼容性

- 复用仓库现有持久化日线读取及发布 generation；结构响应缓存最多保留 32 份快照，并包含标的、周期、读取窗口、算法版本/参数、数据 generation 和收盘截止边界。数据正在发布或读取前后版本不一致时不发布混合快照，也不混入盘中最新缓存。图表以 `readonly=True` 读取 generation，既不初始化版本标记，也不恢复中断的发布状态，其他调用方默认行为不变。
- 不加入高频 `quotes_updated` 失效列表，不在行情回调线程全量计算结构。重新进入和手动刷新会获取当前可用数据；同日历史修订依赖已有仓库数据版本失效。
- CZSC 结果不写 enriched Parquet，不修改策略、监控、回测成交或历史配置。
- 前端结构图层参数可选，未传入时现有 K 线行为不变；扩展未注册时详情入口不出现。
- 保留工作区已有全部未提交修改；实施时逐文件合并，不提交或推送。
