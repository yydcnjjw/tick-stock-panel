# ADR 0003：使用 chan.py 结构和逐根确认事件

状态：已采纳。日期：2026-09-24。

CZSC 旧接口只提供笔结构与六个辅助信号，其均线二、三买不能直接别名为 chan.py 原生二、三类点。最终快照回填历史端点还会将确认前未知的信息带入回测。

采用固定上游 commit、隔离命名空间的 chan.py 计算核心。通过现有标准化本地行情逐根驱动，图表展示笔、段两层候选及结构，策略仅使用笔层进入原生保留区后的确认事件；确认日与端点日分别记录，首次可计算只建立基线。交易保持确认后的次交易日开盘。旧策略停用但保留源文件及历史，新信号和模板使用独立 ID。

完整参数、边界、兼容名字、模板及验证方式见 [chan.py 契约](../chan-engine.md)。本决策替代 ADR 0002 的计算引擎及事件规则，保留其发布快照、缓存、来源隔离与收盘边界原则。固定版本仍可能在特定行情上违反保留区假设，运行时遇到已确认点改变会报错关闭信号发布；不将异常解释成无信号。
