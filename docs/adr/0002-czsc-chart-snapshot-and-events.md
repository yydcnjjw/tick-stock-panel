# 结构快照与辅助事件共用回放，保留不同时间语义

CZSC 图表沿用既有日线辅助信号的版本、参数和逐根回放过程，额外收集各有效数据段的结构快照。结构在截止时点形成，端点日期不能解释为当时已经确认；辅助事件仍标在首次成立触发日，不能由最终结构反推回填，避免图表与策略各自维护一套判定。

前端通过现有详情底部插槽进入独立页面，并扩展共享 K 线组件的可选图层。后端使用薄 API 与独立服务读取已发布本地日线，不混入实时内存尾行；缓存沿用发布 generation，图表读取禁止初始化或恢复发布状态。发布保证批次一致性，不等同供应商对每根日线的最终定版，页面保留这一数据边界。

2026-09-18 扩展到 1 分钟、5 分钟、30 分钟和周线时，继续共用逐根回放与首次触发语义，由图表输入适配层负责周期聚合、闭合与缺口判定。日线策略和回测入口仍固定日线；新增周期不改变成交契约。分钟历史只读本地落盘数据，用分区指纹校验快照，不在图表 GET 请求中同步远程数据；这样保留读取边界，代价是历史覆盖依赖用户现有同步。
