# 伦敦金四周期图

在「设置 → 扩展页面」新建页面，模板选择「伦敦金四周期图」，填写菜单标识和名称后保存。
该模板直接使用伦敦金数据能力，不需要导入表格或选择分组字段。
页面统一从 `/analysis/<菜单标识>` 打开，并进入扩展页面和菜单管理流程。
例如菜单标识 `spot_gold` 对应 `/analysis/spot_gold`；原 `/spot-gold` 地址跳转至此。
编辑名称后，侧栏和页面标题同步更新；删除配置后该扩展页面不再可访问。
菜单分组填写「商品行情」后，侧栏显示「商品行情 → 伦敦金」。后续扩展页面填写
相同分组即可归入该菜单；留空保持一级菜单。旧配置没有分组字段时仍按原方式显示。
菜单设置中的顺序与隐藏作用于子页面，分组位置取首个可见子页面的位置。

从侧栏「商品行情 → 伦敦金」进入后，默认显示日线，每次只显示一个周期。
图表展示参考 chan.py 结构图：顶部切换周线、日线、4 小时或 1 小时，图表卡片内
依次展示横向图层开关、均线控制、全宽 K 线及 MACD 子图。可拖动或缩放查看历史，
开关控制分型、已完成笔、线段、笔中枢、线段中枢和未完成结构，切换周期保留图层选择。
实线表示引擎已确认，虚线表示引擎尚未确认，不等于严格买卖点。

均线控件与股票／指数 chan.py 页共享，支持 SMA/EMA 5/10/20/60 和真实 5↔10 交叉标记；
在浏览器保存选择，重新进入或切换周期后沿用。SMA/EMA 满 N 根才显示，EMA 采用应用
既有首收盘价种子，MACD 使用 12/26/9 参数。指标基于原始报价计算，未收盘尾值可能变化。
当前黄金源未提供成交量，图表不展示成交量子图；黄金结构接口未提供买卖点候选或确认事件。

数据来自[新浪伦敦金（现货黄金）CFD](https://finance.sina.com.cn/futures/quotes/XAU.shtml)，
单位为美元/金衡盎司。页面显示抓取时间、各周期结构截至时间及实际输入根数。
伦敦金现货属于场外贵金属市场，当前接入的是现货黄金 CFD 报价，并非交易所黄金期货合约。
参考价取最后一根小时 K 线的收盘字段，可能仍在变化，不是独立实时成交报价。

点击「刷新数据」重新获取四周期。页面不后台轮询；一分钟内重复访问可复用服务缓存。
刷新过程中继续显示旧图，失败时显示提示并保留上次成功时间。
源不可用时通过「设置 → 数据源」查看「伦敦金」能力及生效提供方。

当前源周/日线从 2021-01-04 起计算，小时历史以源实际返回范围为准。
周线由日线聚合，周起日为周一。小时横轴使用北京时间结束标签；日线日期来自
供应商。日线按次日 08:00、周线按周六 08:00 保守定版；该规则不是统一市场收盘
时间。未收盘 K 线单独标记并排除在结构计算之外，可能在夜间同时出现两个日期的待定日线。

缠论结构复用应用固定版本的 chan.py，各周期独立计算；K 线周期不等于缠论递归级别。
报价源可能延迟、修订或出现缺口，缺口未全部独立核验，不生成缺失 K 线，也不补零成交量。
页面用于观察结构，不自动给出交易信号。
